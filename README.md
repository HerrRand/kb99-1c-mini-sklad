## :rocket: Как открыть

<details open>
<summary><b>Развернуть пошаговую инструкцию</b></summary>

1. Установите **1С:Предприятие 8.3**
2. [Скачайте репозиторий (ZIP)](https://github.com/HerrRand/kb99-1c-mini-sklad/archive/refs/heads/main.zip)
3. Распакуйте архив
4. Запустите 1С:Предприятие 8.3 и создайте новую информационную базу
5. Новую информационную базу откройте в режиме **Конфигуратор**
6. В Конфигураторе выберите:
   **Конфигурация → Открыть конфигурацию из файлов…**
7. Укажите папку с выгрузкой (распакованным архивом) и нажмите загрузить
8. Дождитесь загрузки, затем выполните:
   **Конфигурация → Обновить конфигурацию БД (F7)**.
9. Запустите **1С:Предприятие** (F5) — подсистема «Мини-Склад» доступна в интерфейсе.

</details>
<details>
<summary><b>ℹ️ Примечание о версии платформы</b></summary>
